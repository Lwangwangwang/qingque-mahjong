玩法与计分

玩法预设

经典大众麻将：136 张牌，可吃碰杠，常见番型计分。
四川麻将（简化）：108 张序数牌，开局顺时针换三张并定缺；禁止吃牌，须先打完定缺牌并缺门后才能胡；本版首家和牌后结算。
北方推倒胡：可吃碰杠，满足基本牌型即可推倒，最多计 2 番。
自定义：标准牌组，可自行开关吃牌。

操作与杠牌

同一张弃牌同时满足多种条件时，胡、明杠、碰和所有可行吃法会同时列出，由玩家选择。摸到四张相同牌可暗杠；已经碰出的刻子再摸到第四张可补杠。每次杠后补牌并重新判断自摸、再次杠牌与出牌。

机器人难度

休闲级出牌随机性较高；标准级以尽快听牌和提高有效进张为首要目标；高手级在此基础上估计放铳风险。机器人积分明显落后时会降低防守权重，提高做清一色、混一色、碰碰和等大牌的倾向。机器人只使用自己的手牌和公开信息。

统一休闲积分规则

基本和牌 1 番；自摸 +1 番、碰碰和 +2 番、混一色 +3 番、清一色 +5 番、七对 +4 番、箭牌刻子 +1 番，8 番封顶。基础分 = 1000 × 2番数−1。点炮由放铳者支付；自摸由三家分别支付。庄家参与支付或收款时该笔翻倍。明杠由出牌者支付 1000 分；暗杠由三家各付 1000 分；补杠由三家各付 500 分，四川玩法对应杠分翻倍。

连续比赛

一圈含 4 局，庄家逐局轮换。每局结算后继续，赛程结束按总分排名。

安装青雀麻将

Android / Windows / macOS

使用 Chrome 或 Edge 通过 HTTPS 打开游戏，点击顶部“安装应用”；也可打开浏览器菜单，选择“安装应用”。

iPhone / iPad

使用 Safari 打开游戏，点击底部“分享”按钮，然后选择“添加到主屏幕”。iOS 不会显示系统安装弹窗。

离线说明

首次联网打开后，程序会缓存全部页面和麻将贴图。之后可从桌面图标启动并离线游玩。
